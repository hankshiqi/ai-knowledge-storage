# item_name 商品名称识别优化说明

## 1. 问题现象

导入 HAK 180 相关说明书后，`item_name` 被识别为以下形式：

- `兄弟HAK 180烫金机`
- `Brother HAK 180烫金机`

期望的规范名称是：

```text
HAK 180烫金机
```

## 2. 原因分析

问题发生在商品名称识别阶段，不是前端显示或 Milvus 拼接造成的。

2026-10-25 的导入日志中，模型已经返回了带品牌的结果，随后程序原样写入 Milvus：

```text
识别到的item_name是兄弟HAK 180烫金机
插入 item_name: 兄弟HAK 180烫金机

识别到的item_name是Brother HAK 180烫金机
插入 item_name: Brother HAK 180烫金机
```

原提示词要求“最好是带品牌、型号和名称的完整商品名称”。同时，前 10 个切片中既包含产品标题 `HAK 180 烫金机`，也包含大量版权、售后、经销商和支持网站中的 `Brother/兄弟`。模型因此把制造商名称误判为商品名称的一部分。

## 3. 本次优化内容

### 3.1 标题优先，降低模型猜测

文件：`app/rag/import_/item_name_service.py`

新增 `extract_item_name_from_titles()`，识别顺序如下：

1. 遍历前 `CHUNKS_SPLIT_TOP_NUMBER` 个切片的标题。
2. 去除 Markdown 标题符号和切片编号后缀，例如 `## HAK 180 烫金机-1`。
3. 忽略“目录、简介、警告、设备”等不包含商品型号的通用标题。
4. 只接受同时包含字母和数字的型号标题。
5. 如果标题只有型号，则从正文中识别“型号 + 是一款/是一种 + 产品类别”的句式。

因此，安全手册可以直接从 `## HAK 180 烫金机-1` 得到规范名称；使用说明书可以从 `HAK 180 是一款烫金机` 得到规范名称。满足条件时直接返回，不调用 LLM。

### 3.2 规范化低置信度结果

文件：`app/rag/import_/item_name_service.py`

新增 `normalize_item_name()`，统一处理格式和文档标题后缀：

- 去除引号和代码标记；
- 去除“商品名称：”“产品名称：”等字段标签；
- 合并连续空白；
- 去除首尾标点；
- 去除末尾的 `用户手册`、`使用说明书`、`说明书`、`操作手册`、`产品手册`、`用户指南` 等文档类型后缀；
- 文件名兜底也经过同样的规范化，避免后缀绕过清洗逻辑。

例如 `双色打印机 GC251DNS用户手册` 会规范为 `双色打印机 GC251DNS`。

该函数不再硬编码删除 `Brother` 或其他品牌，避免把其他产品的合法品牌误删。它只作为标题提取失败、必须调用模型时的输出兜底。

### 3.3 调整识别提示词

文件：

- `app/resources/prompts/item_name_recognition.prompt`
- `app/shared/runtime/prompts/item_name_recognition.prompt`

提示词现在要求：

- 优先使用文件标题、章节标题或产品首次介绍中的正式名称；
- 不要把只出现在版权、售后、经销商、网站或责任声明中的制造商名称加入商品名；
- 只返回商品名称，不返回解释或字段标签。

两个 prompt 文件保持同步，避免不同运行入口读取到不同规则。

## 4. 优化后的处理流程

```text
切片
  |
  v
标题/产品简介提取
  |-- 成功 --> 规范化 --> 写入 item_name 和 Milvus
  |
  `-- 失败 --> LLM 识别 --> 规范化 --> 写入 item_name 和 Milvus
```

这个流程把文档中最明确的结构化证据放在模型推断之前，减少版权和售后段落对识别结果的影响。

## 6. 生效方式

修改代码不会自动改变已经写入 Milvus 的旧记录。需要重新导入相关说明书：

1. 使用新的代码重新执行导入流程。
2. 新商品名集合会按 `file_hash` 删除同一文件版本的旧记录；旧集合没有哈希字段时不会再按 `file_title` 删除，避免同名不同内容的文件互相覆盖。详见 `docs/document_deduplication_incremental_update.md`。
3. 新记录会写入 `HAK 180烫金机`。
4. 刷新前端或重新查询，确认 `item_name` 已更新。

如果只修改代码而不重新导入，页面仍可能显示旧的 `Brother HAK 180烫金机` 或 `兄弟HAK 180烫金机`，这是数据库中已有数据的正常表现。

## 7. 后续扩展建议

如果后续文档的产品名称不在标题中，也不符合“型号 + 产品简介”句式，才进入 LLM 兜底流程。届时可以继续增加通用的标题识别规则或让解析阶段输出明确的产品标题字段，不建议通过不断增加品牌黑名单解决问题。
